# Prixie Roxan — Cloud Automation & AI Integration Portfolio

A static portfolio site with **interactive demo replicas** of production cloud
services I've built: document automation, large-scale spreadsheet processing,
AI-platform analytics, and Model Context Protocol (MCP) integrations.

> ⚠️ **Demos use fabricated sample data only.** No real, confidential, or
> client information is included. These are de-identified replicas of the
> systems' user-facing behavior — no backend, no secrets, no live connections.

## Pages

| File | What it shows |
|------|---------------|
| `index.html` | Portfolio landing — all projects |
| `demo-spreadsheet-filter.html` | Large-file filter + billing console wizard |
| `demo-dashboard.html` | AI usage analytics dashboard (KPIs, growth chart, RBAC) |
| `demo-loan-docs.html` | Loan document generator (JSON → DOCX preview) |
| `demo-mcp.html` | MCP server fleet + simulated tool calls |
| `styles.css` | Shared styling |

## Run locally

Just open `index.html` in a browser — it's fully static, no build step.

## Deploy

Hosted free on GitHub Pages (Settings → Pages → branch `main`, root).
