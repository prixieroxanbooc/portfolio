Document automation service

Loan Document Generator

A REST microservice that fills Word (DOCX) templates from a JSON payload — two document bundles, 54 fields total. It is a pure templater: it inserts caller-supplied values verbatim and performs no financial computation, so legal/finance review stays in control. Fill the form to see the request it would send and a rendered preview.

Why no auto-computation?

Interest, effective rate, documentary stamp tax, and deductions are not calculated by the service — they arrive pre-computed from the upstream system after legal/finance review. The service's only job is faithful placeholder replacement, which keeps the output auditable and the compliance boundary clean.
